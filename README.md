# yukonChromeExtension

这是一个功能强大的个人专属浏览器助手，集成了视频倍速控制、自动切集、代理管理以及网页限制解除等多种实用功能。

## 安装说明

1. 下载并解压本项目代码。
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`。
3. 开启右上角的 **“开发者模式” (Developer mode)**。
4. 点击 **“加载已解压的扩展程序” (Load unpacked)**，选择本项目所在的文件夹。

## 核心功能

- **视频倍速增强**:
  - **长按快进**: 长按 `ArrowRight` (右方向键) 视频以 2.0x 倍速播放，松开即恢复。
  - **自动起播**: 长按倍速时若视频处于暂停状态，插件将自动尝试恢复播放。
  - **智能搜索**: 支持深度搜索 Shadow DOM 及 iframe 内部的播放器。
- **快捷切集**:
  - 使用快捷键 `[` (上集) / `]` (下集) 自动查找并点击页面上的导航按钮。
  - 支持启发式文本匹配与 URL 模式预测。
- **超级复制粘贴**:
  - 解锁网页右键限制、选择限制以及复制粘贴限制。
  - 智能拦截干扰事件，同时确保不影响播放器等正常交互。
  - 飞书 / Lark 页面会在加载初期改写 XHR / fetch 权限响应中的复制能力位，并提供带纯文本和 HTML 的选区复制兜底；切换开关后需刷新飞书页面。
- **强制暗色模式**:
  - 在可注入网页中一键切换全站暗色显示。
  - 使用全局反色与媒体还原策略，尽量保持图片、视频和画布内容的原始观感。
- **飞书云文档快捷输入**:
  - 在飞书云文档页面按 `Ctrl + 4` 触发 LaTeX 公式块输入。
  - 按 `Ctrl + 5` 会通过飞书编辑器居中当前行，再触发 LaTeX 公式块输入；若快捷键事件未被飞书接管，插件会改为点击飞书自身的居中控件。
  - 可在插件设置页直接录入这两个操作的自定义页面快捷键。
- **代理控制器**:
  - **一键切换**: 在“系统代理”与“直接连接 (No Proxy)”模式间快速切换。
  - **解决冲突**: 有效解决部分网站因代理导致的“不提供服务”或连接缓慢问题。
- **通用 Cookie 导出与 MCP**:
  - 一键导出当前网站，或在设置中输入任意 HTTP/HTTPS 域名；保留 HttpOnly、域名、路径和同名项。
  - 可按站点开启自动更新，文件直接保存到系统临时目录下的 `yukonChromeExtension/cookies/域名.cookies.json`，不弹出位置选择框。
  - 配套本机 MCP 和命令行脚本可将指定站点的 Cookie 保存到系统临时目录或指定目录，并返回文件名和完整路径。
  - 首次运行需要重新加载扩展，以及安装本机桥接；详见 [Cookie 导出 MCP 说明](mcp/cookie-export/README.md)。
- **UI/UX 优化**:
  - **精美指示器**: 倍速或快进时在屏幕上方显示精致的磨砂玻璃质感提示。
  - **状态角标**: 插件弹出页（Popup）头部带有状态角标，支持直接点击切换状态，操作更高效。

## 设置管理

### 飞书文档一键导入掘金

在空白掘金草稿点击“从飞书导入”，直接在掘金页面选择已打开的飞书文档或粘贴文档链接，再点击“开始导入”。本机服务通过官方 `lark-cli` 的用户身份导出 Markdown，将飞书图片下载并转存到掘金图床，再交给掘金原生文件导入。页面显示步骤、耗时和图片张数；临时文件在成功或失败后自动清理。详见 [使用与限制说明](docs/feishu-juejin-import.md)。

1. 在扩展程序列表或工具栏点击图标进入设置页。
2. **白名单管理**: 自定义哪些域名可以使用视频控制功能。
3. **状态切换**: 通过开关或标题栏的快捷角标，控制代理模式、超级复制与暗色模式的开启/关闭。

## 实现原理

- **HTML5 Video API**: 标准化控制媒体播放速率。
- **MutationObserver**: 持续监听并清理网页干扰元素（如特定横幅广告）。
- **Chrome Proxy API**: 动态修改浏览器代理配置。
- **Event Interception**: 捕获并停止阻止用户操作的 DOM 事件。
- **Feishu Permission Hook**: 在页面主世界、权限请求返回阶段仅开启前端 `copy` 能力位，不改动文档内容或服务端权限。
- **Content Script CSS Injection**: 通过内容脚本向页面注入暗色模式样式，并监听设置变化即时切换。
